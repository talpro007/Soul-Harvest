# Soul-Harvest



**How to launch:**
download Build/ and run Soul\_Harvest.exe



**Controls:**

AD/L3 - Move

Space/A - Jump (Hold to jump higher)

WS/R3 - Camera

M1/X - Attack

WASD/L3 + M1/X - Directional attack

M2/RB - Cast

Q/B - Heal
